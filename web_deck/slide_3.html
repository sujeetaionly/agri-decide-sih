TECHNICAL APPROACH
🛠️ Technologies to be Used
Frontend PWA Layer 📱
React / Next.js + Tailwind CSS + Lucide Icons
Mobile-first, touch-friendly wizard (>48px targets), Web Speech API for Hindi voice input and SpeechSynthesis audio playback. GIGW accessibility compliant.
Backend API Core ⚡
Python 3.11 + FastAPI + PostgreSQL / SQLite
Asynchronous, high-throughput REST API with strict Pydantic validation schemas, storing official CACP cultivation cost norms and Agmarknet historical mandis.
Predictive AI/ML Engine 🤖
scikit-learn + XGBoost Regressor + LightGBM
District-trained XGBoost Yield Regressor with delay penalty curves + seasonal harvest-month wholesale mandi price forecasting models.
Deployment & Infrastructure ☁️
Docker + NIC Cloud / MeghRaj / Render
100% Free and Open-Source (FOSS) architecture with zero per-transaction API fees; lightweight PWA (< 2MB bundle) with offline-first caching.
🔄 Methodology & Implementation Pipeline
STAGE 1
Zero-Friction Ingestion & Profile Detection
Farmer selects District/Taluka or taps GPS. Engine auto-fetches SoilGrids GIS soil texture and ICAR agro-climatic baseline. Farmer inputs water source, budget, and owned machinery.
STAGE 2
Sowing Window & Agro-Climatic Validation
Planned sowing date is cross-referenced with crop-specific ICAR calendar windows, computing delay penalties: 🟢 Optimal Window, 🟡 Late (Yield Penalty), 🔴 Closed.
STAGE 3
Predictive Yield & Dynamic Economic Modeling
XGBoost calculates expected yield (qtl/acre). CACP engine deducts machinery rental savings if tractor/sprayer is owned. Computes Net Profit = (Yield × Mandi Price) - Adjusted Cost.
STAGE 4
Explainable 4-Crop Scorecard & 120-Day Action Timeline
Renders side-by-side comparison ranked by ₹/Day with 'Why' reasoning bullets, live "What-If" climate shock sensitivity sandbox, and a 120-day milestone calendar.
